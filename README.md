# ぷくともちの食べ歩き

「ぷくともち」シリーズのスマホ向けWeb絵本です。

## 第1話 横浜中華街

紫色で元気な「ぷく」と、白〜水色でのんびり屋の「もち」が、横浜中華街で食べ歩きを楽しみます。

全11ページ：

1. 横浜中華街に到着
2. 食べ物の匂いに気づく
3. 肉まんを発見
4. 肉まんを食べて「あちち！」
5. 小籠包を食べる
6. 焼き小籠包を半分ずつ食べる
7. ごま団子を発見
8. 食べすぎてお腹いっぱい
9. 中華街を散歩
10. 山下公園で休憩
11. 夕暮れで「また食べにこようね」

## 操作

- 「前へ」「次へ」ボタン
- ページドット
- スマートフォンの左右スワイプ
- キーボードの左右キー、Home、End
- URLの `#page-arrival` などから指定ページを直接表示

## ローカルで確認

静的ファイルとして配信します。

```powershell
node scripts/serve.mjs
```

ブラウザで `http://127.0.0.1:4173/` を開いてください。

静的参照とページ構成の検査：

```powershell
node scripts/check-static.mjs
```

## 表示とアクセシビリティ

- 320px以上のスマートフォン幅とPC表示に対応
- 現在ページと全ページ数を表示
- 操作ボタンとページドットに日本語のラベルを設定
- 現在ページをライブ領域で通知
- キーボード操作とフォーカス表示に対応
- `prefers-reduced-motion` に対応

GitHub Pagesの公開設定はまだ含めていません。
